# 11ai Utilities

Ten general-purpose skills for running whole repository tasks under Git discipline, text compression, reverse engineering, reviews, analytics, publication CMS, calls to action, project sites, and scaffolding new operator plugins.

## Choose a skill

| Skill | Use it for |
| --- | --- |
| [`11ai-director-git-main`](./skills/11ai-director-git-main/SKILL.md) | Running a complete repository task directly on main: sync a clean tree, do the task, quality-check, and report — committing or pushing only when explicitly asked |
| [`11ai-director-git-branch`](./skills/11ai-director-git-branch/SKILL.md) | Landing a complete repository task through a branch and pull request: branch from a clean tree, do the task, open a detailed PR, address review comments — merging or closing only when explicitly asked |
| [`11ai-compression`](./skills/11ai-compression/SKILL.md) | Shortening Markdown guidance locally while preserving its technical structure |
| [`11ai-operator-plugin-creator`](./skills/11ai-operator-plugin-creator/SKILL.md) | Scaffolding a new `11ai-operator-TOOL` plugin that matches the house pattern and passes validation |
| [`11ai-platform-cta`](./skills/11ai-platform-cta/SKILL.md) | Adding context-aware platform calls to action with measurable conversion events |
| [`11ai-publications-cms`](./skills/11ai-publications-cms/SKILL.md) | Building a file-backed publications CMS with validated content and routes |
| [`11ai-reverse-engineering`](./skills/11ai-reverse-engineering/SKILL.md) | Producing a sanitized blueprint for rebuilding and modernizing a locally cloned repository |
| [`11ai-roast`](./skills/11ai-roast/SKILL.md) | Giving a blunt, prioritized, read-only critique of code or another work product |
| [`11ai-vercel-analytics`](./skills/11ai-vercel-analytics/SKILL.md) | Adding or verifying Vercel Web Analytics in a web application |
| [`11ai-www`](./skills/11ai-www/SKILL.md) | Examining a project and building a repo-driven site that displays it, in a `www/` folder or embedded app |

The two directors wrap a task in a Git transaction; they do not define the task. Name the work (or the task skill) in the same request, and the director handles synchronization, cleanliness, rollback, and reporting around it.

The compression skill includes local scripts for transforming and validating Markdown. The roast skill is read-only and delivers a one-off critique rather than editing code.
