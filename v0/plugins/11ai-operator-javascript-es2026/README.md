## Safety contract

Inspect versions, configuration, source ownership, module mode, and target browser, server, worker, or embedded JavaScript runtimes before editing.

Never guess ECMAScript support, module format, runtime globals, bundler behavior, or error-handling policy. Preserve the package manager, lockfile, and public contracts.

Ask before changing module format, public exports, serialized data, event behavior, dependency versions, or generated bundles. Preview callers, exports, generated output, and deployment effects.

Never print or commit tokens, cookies, personal data, full request bodies, or server-only environment values. Count files and inspect diffs before codemods, bulk renames, formatting sweeps, dependency upgrades, or output replacement.
