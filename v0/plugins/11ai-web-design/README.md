# 11ai Web Design

Four complementary skills: applying the visual language of `v0/www`, building
or restyling toward a modern-clean aesthetic, giving an existing interface a
deliberate, content-led design direction, or building a whole project website
from the repository's own content.

## Skills

| Skill | Use it for |
| --- | --- |
| [`11ai-design-styleguides`](./skills/11ai-design-styleguides/SKILL.md) | Applying the 11ai foundations, component/layout patterns, compact analytical mode, and accessible shadcn visualization guidance |
| [`11ai-modern-clean-ui`](./skills/11ai-modern-clean-ui/SKILL.md) | A standalone, brand-neutral styleguide for the contemporary modern-clean look (neutral palette plus one accent, real whitespace, restrained motion) — tokens, components, and states for any codebase |
| [`11ai-pimp-my-ui`](./skills/11ai-pimp-my-ui/SKILL.md) | Reaching one deliberate design direction for existing user-facing content and executing it with the codebase's own tools |
| [`11ai-www`](./skills/11ai-www/SKILL.md) | Building a project website that scans the repository as its source of truth, so content, counts, and catalog pages update automatically as the project changes |

The first three skills supply a shared visual standard for an existing
interface. `11ai-www` is different: it builds the site itself, discovering
what to show from the repository's real files.
