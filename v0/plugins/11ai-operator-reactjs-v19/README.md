Version baseline: React 19.2 within major 19.

## Safety contract

Inspect installed versions, configuration, rendering mode, source ownership, and target supported browser and server rendering environments before editing.

Never guess React version, renderer, server-component support, state ownership, styling, or test environment. Preserve package manager, lockfile, public routes or component APIs, and runtime boundaries.

Ask before changing component APIs, key identity, state ownership, client-server boundaries, dependency versions, or broad rendering behavior. Preview affected consumers, generated output, cache behavior, and deployments.

Never print or commit tokens, session data, private server values, serialized personal data, or full production props. Count files and inspect diffs before codemods, bulk moves, dependency upgrades, cache invalidation, or generated-output replacement.
