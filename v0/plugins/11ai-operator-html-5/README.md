# 11ai HTML5 operator

Ten standalone skills focused on current HTML5 authoring: semantic documents, accessible forms, media, metadata, and browser-native structure, with read-first checks around public contracts, compatibility, generated output, and state-changing operations.

Version baseline: HTML5, represented by the current WHATWG HTML Living Standard (last updated 20 July 2026), verified 31 July 2026. The bare `-5` suffix follows the requested public HTML5 family; the content follows the continuously maintained standard rather than a frozen W3C snapshot.

## Safety contract

Inspect the installed version, active configuration, target browsers and assistive technologies, and existing conventions before editing.

Never guess document language, supported browsers, form submission behavior, or generated-template ownership. Preserve the repository's package manager, source ownership, and public contracts.

Ask before removing content, changing form names or submission targets, rewriting heading or landmark structure, or replacing metadata consumed by crawlers. Preview affected files, generated artifacts, and consumers before broad changes.

Never print or commit form payloads, embedded tokens, private URLs, or server-only environment values. Keep credentials and server-only values out of client-visible output.

Count files and inspect diffs before codemods, formatting sweeps, bulk renames, generated-output replacement, or dependency upgrades. Run focused checks and a production-mode verification before reporting success.
