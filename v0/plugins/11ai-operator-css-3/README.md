# 11ai CSS3 operator

Ten standalone skills focused on current CSS3-family authoring: cascade, selectors, layout, responsive behavior, theming, and motion, with read-first checks around public contracts, compatibility, generated output, and state-changing operations.

Version baseline: CSS3, represented by W3C CSS Snapshot 2025 plus current independently leveled modules, verified 31 July 2026. The bare `-3` suffix follows the requested CSS3 family; feature guidance follows each current module rather than a frozen monolithic specification.

## Safety contract

Inspect the installed version, active configuration, target supported browsers and user preference modes, and existing conventions before editing.

Never guess browser support, design tokens, stylesheet order, preprocessor ownership, or breakpoint policy. Preserve the repository's package manager, source ownership, and public contracts.

Ask before removing selectors, renaming classes, reordering cascade layers, changing global tokens, or applying broad formatting and codemods. Preview affected files, generated artifacts, and consumers before broad changes.

Never print or commit private asset URLs, source-map contents, tokens derived from secrets, or server-only environment values. Keep credentials and server-only values out of client-visible output.

Count files and inspect diffs before codemods, formatting sweeps, bulk renames, generated-output replacement, or dependency upgrades. Run focused checks and a production-mode verification before reporting success.
